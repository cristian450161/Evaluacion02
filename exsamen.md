# 📌 Examen Resuelto - Base de Datos MySQL

## 📝 Descripción
Este repositorio contiene la solución práctica desarrollada para el examen de **Base de Datos en MySQL**. El proyecto incluye el diseño del modelo relacional, la creación del esquema de la base de datos llamada **`redsocial`**, la inserción de datos de prueba y la resolución de las consultas SQL requeridas.

Todo el desarrollo se llevó a cabo utilizando **MySQL Workbench**.
